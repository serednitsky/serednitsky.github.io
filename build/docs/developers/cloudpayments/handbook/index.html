Для регулярных платежей необходимо установить ограничения на отправку повторных запросов, в случае если были получены коды ошибок из группы «Безусловно негативные». Таким образом, последующие регулярные платежи проходить не будут, необходимо повторно провести установочную операцию.

При 2-ух попытках из группы «Условно негативные» и «Временно негативные» будет происходить блокировка проведения оплаты в течение 24-х часов (суток). Таким образом, данное правило необходимо учесть на своей стороне для кодов ошибок ниже.
