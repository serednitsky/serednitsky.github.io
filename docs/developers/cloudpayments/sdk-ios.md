# SDK для iOS

SDK позволяет интегрировать прием платежей в мобильные приложение для платформы iOS.  
Основная версия находится на <a href="https://gitpub.cloudpayments.ru/integrations/sdk/cloudpayments-ios" target="_blank" target="_blank">GitHub</a>.  

Из приложения вы узнаете как получить карточные данные, сформировать криптограмму, провести [3-D Secure авторизацию](general-information.md#3-d-secure) и выполнить платеж на iPhone или iPad.

**Условия использования**:  

*  Если вам необходимо будет пересылать данные через ваш сервер, то для него не потребуется сертификация PCI DSS, так как карточные данные на него приходят в зашифрованном виде, а ключи для расшифровки есть только в платежном шлюзе CloudPayments, в приложении и библиотеке их также нет;
*  Данные карты можно вводить с клавиатуры или сканировать камерой например, через <a href="https://www.card.io/" target="_blank">card.io</a>. Полный номер карты и CVV нельзя сохранять или записывать в лог;
*  Мобильный SDK нельзя использовать для мобильных терминалов (mPos). Единственное применение — в приложениях, которые будут установлены на телефонах и планшетах ваших покупателей;
*  По правилам <a href="https://developer.apple.com/app-store/review/guidelines/#purchasing-currencies" target="_blank">AppStore</a> разработчик мобильного приложения имеет право принимать платежи с использованием сторонних платежных систем только для продажи нецифровых товаров или цифровых товаров, которые можно использовать вне приложения.
