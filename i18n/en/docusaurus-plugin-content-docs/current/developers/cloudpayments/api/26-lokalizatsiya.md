# Localization

By default, the API returns user messages in Russian. To receive responses localized for other languages, pass the **CultureName** parameter in the  request.

**List of supported languages:**

Language | Timezone  | Code
--------- | ------- | -----------
Russian | MSK | ru-RU
English | CET | en-US
Latvian |	CET | lv
Azerbaijani | AZT |	az
Russian | ALMT | kk
Ukrainian | EET | uk
Polish | CET | pl
Vietnamese | ICT | vi
Turkish | TRT | tr
