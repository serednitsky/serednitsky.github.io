Processing 3D Secure

To perform 3D Secure authentication you must redirect the payer to the address specified in the AcsUrl parameter of the server response, passing the following parameters:

  • MD: TransactionId parameters from the server response
  • PaReq: the parameter of the same name from the server response
  • TermUrl: the return URL on your website where the payer is redirected after authentication
Note that parameter names are case-sensitive.

After authentication, the payer will be redirected to the TermUrl with the MD and PaRes parameters passed by the POST method.

To complete the payment, execute the following Post3ds method:

Endpoint: https://api.cloudpayments.ru/payments/cards/post3ds

Request parameters:

ParameterFormatRequiredDescription
TransactionIdlongYesThe MD parameter value
PaResstringYesThe value of the parameter with the same name

In response to a well-formed request, the server returns information about either a successful transaction or a declined transaction.
